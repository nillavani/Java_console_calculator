# Java Console Calculator

##  Description
This project is a simple Java Console Calculator that performs basic arithmetic operations using console input and output. The program allows users to repeatedly perform calculations until they choose to exit.

---

##  Objective
The objective of this project is to understand:

- Java syntax
- Methods
- Loops
- Conditional statements
- User input using Scanner class
- Basic logic building

##  Tools Used

 Java (JDK)
 VS Code
 Terminal / Command Prompt



##  Features

- Addition
- Subtraction
- Multiplication
- Division
- Divide-by-zero handling
- Menu-driven program
- Repeated calculations using loop

##  Concepts Used

- Classes and Objects
- Methods
- Scanner Class
- if-else Statements
- switch-case
- do-while Loop
- Arithmetic Operations
